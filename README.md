# Great Dormass Digital School Portal

Created by Justice Amoh.

## What is included
- Responsive Great Dormass homepage
- School identity and official information
- Six academic programmes
- SHS 1, SHS 2 and SHS 3 library sections
- Core/elective/general resource cards
- Searchable resource library
- Links to official Ghana Ministry of Education curriculum materials
- Great Dormass photo gallery
- School video/media links
- Admissions and contact sections
- Creator credit: Justice Amoh

## Important about the books
The website deliberately uses links to the official Ministry of Education Curriculum Resources Microsite instead of copying commercial copyrighted textbooks into the package. The official microsite provides learner resources for Year 1, Year 2 and Year 3, plus General/Library/Supplementary materials.

For a fully offline version containing downloaded PDFs, only materials that are explicitly permitted for redistribution should be bundled. If you have the PDF files or permission to redistribute them, they can be placed in `books/` and the library cards can be changed to local files.

## Deployment
Upload all files in this folder to GitHub, then deploy the repository on Vercel, Netlify, GitHub Pages, or another static host.


The library now covers a comprehensive SHS subject directory for Years 1–3 and links students to the official Ministry year directories, where the downloadable notes/materials are hosted.
